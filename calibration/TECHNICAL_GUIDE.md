## 1. 校正原理

### 1.1 問題描述

由於鏡頭畸變或拍攝角度問題，原始網格影像中的線條可能不是水平/垂直的。校正的目標是將彎曲的網格線變成標準的正方格。

### 1.2 TPS 薄板樣條變換

TPS (Thin Plate Spline) 是一種非線性插值方法，可以建立平滑的變形映射。

**優點**：
- 平滑的非線性變換
- 精確通過控制點
- 適合處理局部畸變

**數學原理**：

TPS 擬合函數的形式為：

```
f(x, y) = a₀ + a₁x + a₂y + Σᵢ wᵢ U(||(x,y) - (xᵢ,yᵢ)||)
```

其中 `U(r) = r² log(r)` 是基底函數。

## 3. 演算法細節

### 3.1 形態學線條分離

```python
# 水平線核 (40x1)
h_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (40, 1))
h_lines = cv2.morphologyEx(bin_img, cv2.MORPH_OPEN, h_kernel)

# 垂直線核 (1x40)
v_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (1, 40))
v_lines = cv2.morphologyEx(bin_img, cv2.MORPH_OPEN, v_kernel)
```

### 3.2 亞像素精度

使用 `cv2.cornerSubPix()` 將交點定位精度提升至亞像素等級：

```python
criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.01)
pts = cv2.cornerSubPix(gray, pts, (5, 5), (-1, -1), criteria)
```

這對最終校正精度至關重要，可將誤差從像素級降至 0.1~0.2 像素。

### 3.3 分群演算法

使用 tolerance-based 分群將交點依 Y 座標分成列：

```python
def cluster_1d(vals, tol):
    order = np.argsort(vals)
    groups = []
    cur = [order[0]]
    for idx in order[1:]:
        if abs(vals[idx] - vals[cur[-1]]) <= tol:
            cur.append(idx)
        else:
            groups.append(cur)
            cur = [idx]
    groups.append(cur)
    return groups
```

### 3.4 TPS 平滑參數

`smooth` 參數控制擬合的平滑度：

| smooth 值 | 效果 |
|-----------|------|
| 0 | 精確通過所有控制點（可能過擬合）|
| 0.1 ~ 1 | 輕微平滑（推薦）|
| 1 ~ 10 | 中度平滑 |
| > 10 | 強力平滑（可能欠擬合）|

```python
rbf_x = Rbf(X, Y, x, function="thin_plate", smooth=1.0)
```

## 4. 驗證指標

### 4.1 格距一致性 (CV)

變異係數 = 標準差 / 平均值

```python
dx = grid[:, 1:, 0] - grid[:, :-1, 0]  # 相鄰點 X 間距
cvx = np.std(dx) / np.mean(dx)          # X 方向 CV
```

| CV 值 | 評估 |
|-------|------|
| < 2% | 優秀 |
| 2% ~ 5% | 良好 |
| > 5% | 需改善 |

### 4.2 直線度 (RMS)

使用最小二乘法擬合直線，計算殘差的均方根：

```python
def line_rms(points):
    x, y = points[:, 0], points[:, 1]
    A = np.vstack([x, np.ones_like(x)]).T
    a, b = np.linalg.lstsq(A, y, rcond=None)[0]  # y = ax + b
    y_fit = a * x + b
    return np.sqrt(np.mean((y - y_fit)**2))
```

| RMS 值 | 評估 |
|--------|------|
| < 0.3 px | 優秀 |
| 0.3 ~ 0.5 px | 良好 |
| > 0.5 px | 需改善 |

### 4.3 總誤差

綜合各指標的加權平均：

```python
E_total = 100 * sqrt(cvx² + cvy² + (rms_h/dbar)² + (rms_v/dbar)²)
```

| 總誤差 | 評估 |
|--------|------|
| < 3% | 優秀 |
| 3% ~ 5% | 良好 |
| > 5% | 需改善 |

## 5. 參數調整

### 5.1 二值化參數

```python
bin_img = cv2.adaptiveThreshold(
    gray, 255, 
    cv2.ADAPTIVE_THRESH_MEAN_C, 
    cv2.THRESH_BINARY, 
    blockSize=31,  # 區塊大小（奇數）
    C=-5           # 常數偏移
)
```

- `blockSize`：增大以處理光線不均
- `C`：調整以改變閾值敏感度

### 5.2 形態學核大小

```python
h_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (40, 1))
```

- 核長度應大於格距的 1.5 倍
- 核寬度保持 1（水平）或高度 1（垂直）

### 5.3 分群容差

```python
tol_y = max(5.0, step_y * 0.4)
```

- 容差過大：不同列可能合併
- 容差過小：同一列可能分裂

### 5.4 TPS 平滑度

```python
SMOOTH = 1.0  # 可調整範圍 0.1 ~ 10
```

- 若校正後仍有波浪狀：降低 smooth
- 若邊緣變形過大：提高 smooth

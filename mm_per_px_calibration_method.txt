================================================================================
mm_per_px 校準方法說明
================================================================================

程式在錄影開始時，使用第一幀影像進行一次性尺度校準。
依序嘗試三個方法，成功即停止：

--------------------------------------------------------------------------------
方法 1（優先）：背景網格檢測 — detect_grid_scale()
--------------------------------------------------------------------------------

前提假設：背景為 5mm 間距的方格紙。

步驟：
  1. 影像轉灰階 → 高斯模糊 (3x3) → Canny 邊緣偵測 (50, 150)
  2. HoughLinesP 霍夫直線偵測，找出影像中的直線段
  3. 依直線角度分類：
     - 角度 < 8° → 水平線，記錄 y 座標
     - 角度與 90° 差距 < 8° → 垂直線，記錄 x 座標
  4. 對水平線的 y 座標（及垂直線的 x 座標）排序、去重（間距 > 1.5 px 視為不同線）
  5. 計算相鄰線的間距 (np.diff)，篩選 2 < diff < 300 的合理值
  6. 取最小間距作為一格的 pixel 數 (px_per_cell)
     - 若水平與垂直都有結果，取兩者平均
  7. 計算：mm_per_px = 5.0 / px_per_cell

合理範圍檢查：結果必須在 0.05 ~ 0.5 之間，否則視為失敗。

--------------------------------------------------------------------------------
方法 2（備用）：Device 尺寸檢測 — detect_device_scale()
--------------------------------------------------------------------------------

前提假設：已知 device 實際尺寸為 9mm (寬) x 6mm (高)。

步驟：
  1. 影像旋轉 90°（順時針）
  2. 用 find_target_and_angle() 以 HSV 色彩遮罩偵測 device 輪廓
  3. cv2.minAreaRect() 取最小外接矩形，得到 width_px x height_px
  4. 確保長邊對應寬 (9mm)，短邊對應高 (6mm)
  5. 計算：
     - scale_from_width  = 9.0 / width_px
     - scale_from_height = 6.0 / height_px
     - mm_per_px = (scale_from_width + scale_from_height) / 2.0

合理範圍檢查：結果必須在 0.05 ~ 0.5 之間，否則視為失敗。

--------------------------------------------------------------------------------
方法 3（Fallback）：預設值
--------------------------------------------------------------------------------

若方法 1 與方法 2 皆失敗，直接回傳預設值：mm_per_px = 0.1

--------------------------------------------------------------------------------
校準後的使用方式
--------------------------------------------------------------------------------

mm_per_px 在第一幀校準後，整段錄影中保持固定不變。
後續每一幀的座標轉換：

  x_mm = x_px * mm_per_px
  y_mm = y_px * mm_per_px

匯出 CSV 時，mm_per_px 會寫入每一列作為記錄。

--------------------------------------------------------------------------------
正常值範圍與異常值判斷
--------------------------------------------------------------------------------

根據所有實驗資料統計：
  - 正常範圍：約 0.22 ~ 0.24 mm/px（大多數檔案落在此區間）
  - 異常值 0.100000：校準失敗，使用了 fallback 預設值
  - 異常值 0.138889：網格或 device 偵測結果偏差過大

若 mm_per_px 明顯偏離 0.22 ~ 0.24 範圍，該筆資料的距離與速度計算可能不準確。

================================================================================
  Test 01: 函數產生器模式切換延遲測試
  Function Generator Mode-Switching Latency Benchmark
  測試日期：2026-05-14
================================================================================

  目的：
    比較三代 SCPI 指令序列在 Keysight 33622A 上的模式切換速度。
    Gen-1（每次重新上傳波形）vs Gen-2（預載+多次寫入）vs Gen-3（單次 compound 指令）。

  設備：
    - 函數產生器：Keysight 33622A (firmware A.02.03-3.15-03-64-02)
    - VISA: USB0::0x0957::0x5707::MY59000656::0::INSTR (USB-TMC)
    - Host PC: Windows, Python 3.14

  方法：
    - 計時範圍：inst.write() 發送到完成
    - 每個場景 50 次測試 + 10 次 warmup（排除 USB bus 初始化延遲）
    - 使用 time.perf_counter()（Windows 下 sub-us 解析度）

  三代策略差異：
    Gen-1: OUTP OFF -> 讀 CSV -> 上傳波形 -> 配置參數 -> OUTP ON（~260ms）
    Gen-2: 預載波形。切換時多條獨立 write + 多個 *WAI（~2-40ms）
    Gen-3: 預載波形。切換時所有指令用「;」串接成單次 USB write + 單個 *WAI（<1ms）

  結果（Gen-3, n=50 trials each）：
    場景                          mean      P99       verdict
    同組極性切換 (Mode 1<->3)     0.347ms   0.723ms   PASS
    同組極性切換 (Mode 2<->4)     0.424ms   1.770ms   PASS
    跨組波形切換 (1->2, 25k->47k) 0.465ms   1.966ms   PASS
    跨組波形切換 (2->1, 47k->25k) 0.425ms   1.281ms   PASS
    電壓調整 (PID routine)        0.350ms   3.957ms   PASS

  Gen-1 結果（對照組, n=50）：
    完整重新上傳切換              mean=268ms  max=367ms

  加速比：
    Gen-3 vs Gen-1: >600x (0.4ms vs 268ms)
    Gen-3 vs Gen-2: ~5-10x

  結論：
    Gen-3 compound SCPI 方法成功將所有 FG 操作控制在 5ms 以內，
    滿足 120fps (8.33ms) frame budget 需求。

  數據檔案：fg_switching_gen3_raw.csv, fg_switching_3gen_raw.csv
